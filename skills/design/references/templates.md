# Control-room skeleton

```
# <ID> — Control Room
> One paragraph: what the effort is; links to the brief and the companion docs. **Status:** <gear, date, what is next>.

## 0. How we run this        — protocol in two lines; house rules; this effort's id prefix; the expected arc
## 1. Framing                — the problem in the user's words; what we are NOT building; inherited ground truth
## 2. Workstream dashboard   — | id | workstream | state ⚪🔵🟡🟢⏸ | doc |
## 3. Ideas worth pushing (I-n)
## 4. Questions (Q-n)        — plain prose, each with a stated default
## 4a. Grounding inputs (GI-n)
## 5. Decision log (D-n, append-only) — date · id · decision · why · alternatives rejected
## 6. ⚑ for Bora             — open flags with defaults; struck through when ruled
## 7. Deferred (tracked)     — each with a revisit-when
```

# Options-doc skeleton
`# <workstream> — options` · hero scenario · proposals (P-n) · forks (per option: buys · costs · prior art ·
cross-links · the lean ➜) · open questions with defaults · where this converges.

# Review hand-over skeleton
For a fresh session: read-in-this-order · check-these (a verdict each) · output shape · house rules (decide nothing,
edit nothing).

# Spike brief skeleton
The question · setup · numbered sub-questions with evidence required · report shape (table + ≤ 10-line recommendation +
found-while-doing) · fence and stop conditions. Scratch only; recommendations, not decisions.
