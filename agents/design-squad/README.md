# The design squad

The design squad works in Cowork and has **no seats** (D-8): it is one Cowork project with instructions
(`project-instructions.md`), the skills `design`, `planning` and the research skill, and the control-room protocol.
Its hand-over to the coding squad is the project repo (design → plan → stage lists); the way back is Found lines,
reviews, STATUS, and flags to Bora. The Gardener is a design-squad persona that lives in a scheduled CLI seat (D-14).

The personas of the brief are **hats of one session**, chosen by the gear and the workstream:

| hat (brief) | when | how |
|---|---|---|
| business expert | framing; use-case and hero sessions | `design` — Framing; "imagine it built" sessions |
| researcher | a question evidence can settle | the research skill; a spike brief for a CLI (`10` DS-11) |
| divergence / convergence manager | every design session | `design` — the gears, the control room, the decision log |
| UX designer | workstreams about screens and flows | `design`, with the hero scenario rendered per option |
| architect | architecture, contracts, the high-level plan | `planning` §1 |
| infrastructure architect | CI/CD, clusters, GitOps | `planning` §1, with the profile's cluster rules |
| planner | stage lists from the plan | `planning` §2–§4 |
| independent reviewer | before convergence | a **fresh** session from a hand-over (`10` DS-10) |
